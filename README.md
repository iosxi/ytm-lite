# yum-lite

YouTube Music の自分のプレイリストを再生するだけの、軽い Windows アプリです。
ブラウザを使わないので、再生中のメモリがブラウザよりずっと少なく済みます。

- exe 1 個で動きます。インストールも追加のランタイムも要りません。
- Windows 10 / 11（64 ビット）。
- 設定は exe と同じフォルダの `yum-lite.ini` に書きます。レジストリには書きません。
  フォルダごと消せば痕跡は残りません。

## 使い方

1. `yum-lite.exe` を起動します。
2. 右下の「…」から「ログイン情報を設定…」を選び、YouTube Music の cookie を貼り付けます（手順は次の節）。
3. 左にライブラリのプレイリストが並びます。選ぶと右に曲が出ます。
   曲をダブルクリック（または Enter）すると、そこから再生します。プレイリストをダブルクリックすると頭から再生します。

ログインしなくても、「プレイリストの URL を開く…」で公開・限定公開のプレイリストは聴けます。

### ログイン情報（cookie）の取り方

プレイリストの一覧と中身を読むのに使います。**曲の再生にはアカウントを使いません。**
cookie は Windows の暗号化（DPAPI）をかけて `yum-lite.ini` に保存します。同じ Windows ユーザーでしか戻せません。

1. ブラウザのシークレット（InPrivate）ウィンドウで music.youtube.com を開き、ログインします。
2. F12 で開発者ツールを開き、［ネットワーク］を「browse」で絞り込みます。
3. ライブラリを開くなどして出てきた `browse`（POST）を選び、［要求ヘッダー］の `cookie` の値をコピーします。
   要求ヘッダー全体をコピーしても構いません（`x-goog-authuser` と `user-agent` も読み取ります）。
4. yum-lite のダイアログに貼り付けて保存し、シークレットウィンドウを閉じます。

ふだん使いのブラウザのウィンドウから取った cookie でも動きますが、ブラウザが cookie を入れ替えたときに
使えなくなることがあります。そのときは取り直してください。

## 操作

| 操作 | |
| --- | --- |
| 再生 / 一時停止 | 中央の丸いボタン、Space（一覧を選んでいるとき）、キーボードの再生キー |
| 次 / 前の曲 | ⏭ / ⏮、Ctrl+→ / Ctrl+←、キーボードの次・前キー |
| シャッフル / リピート | 右下の 🔀 / 🔁（赤いときが有効） |
| 位置を変える | 上の横棒をクリックかドラッグ |
| 読み直す | F5 |

前の曲（⏮）は、3 秒以上鳴っていればその曲の頭に戻ります。
YouTube Music で灰色になっている（再生できない）曲は飛ばします。

キーボードの再生・次・前キーは、yum-lite が起動している間は yum-lite が受け取ります。
ほかのアプリに渡したいときは `yum-lite.ini` に `mediakeys=0` と書いてください。

## 設定（yum-lite.ini）

画面から変えられないものだけ書きます。

| キー | 意味 |
| --- | --- |
| `mediakeys=0` | キーボードのメディアキーを受け取らない |
| `theme=1` / `theme=2` | ライト / ダークに固定する（既定は Windows に合わせる） |
| `debug=1` | 通信の記録を `yum-lite.log` に書く |

## 注意

- YouTube Music の公式アプリではありません。YouTube の非公開の API を使っているので、
  YouTube 側の変更で動かなくなることがあります。
- YouTube から「要求が多すぎる」などと拒まれたときは、安全のため 30 分間、再生の要求を止めます。
- 「子ども向け」に指定された曲など、一部の曲は再生できないことがあります。
