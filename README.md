# ytm-lite

YouTube Music の自分のプレイリストを再生するだけの、軽い Windows アプリです。
ブラウザを使わないので、再生中のメモリがブラウザよりずっと少なく済みます。

- exe 1 個で動きます。インストールも追加のランタイムも要りません。
- Windows 10 / 11（64 ビット）。
- 設定は exe と同じフォルダの `ytm-lite.ini` に書きます。レジストリには書きません。
  フォルダごと消せば痕跡は残りません。

## 使い方

1. `ytm-lite.exe` を起動します。
2. 真ん中の欄の「…」から「ログイン情報を設定…」を選び、ダイアログの手順に沿ってログイン情報を貼り付けます（次の節）。
3. 左にライブラリのプレイリストが並びます。選ぶと右に曲が出ます。真ん中には、再生中の曲のジャケット画像と操作ボタンが並びます。
   曲をダブルクリック（または Enter）すると、そこから再生します。プレイリストをダブルクリックすると頭から再生します。

ログインしなくても、「プレイリストの URL を開く…」で公開・限定公開のプレイリストは聴けます。

### M3U でまとめて開く

プレイリストの URL を 1 行に 1 つ書いたファイル（M3U）を開くと、左の欄にまとめて並びます。
`#EXTINF` の行に書いた名前が、その次の URL の名前になります（無ければ、選んだときに YouTube Music の名前になります）。

```
#EXTM3U
#EXTINF:-1,作業用
https://music.youtube.com/playlist?list=PLxxxxxxxx
#EXTINF:-1,ドライブ
https://music.youtube.com/playlist?list=PLyyyyyyyy
```

- 開き方: 真ん中の欄の「…」→「M3U を開く…」、ウィンドウへのドラッグ＆ドロップ、`ytm-lite.exe 一覧.m3u`
  （すでに起動していれば、起動している方に並びます）。
- 並べるだけで、YouTube には何も送りません。中身は、選んだプレイリストの分だけ取りに行きます。
- 最後に開いた M3U は覚えておき、次の起動と「読み直す」（F5）で読み直します。M3U に書き足した行も並びます。
- URL だけを並べたファイルでも、ID（`PL…`）だけの行でも読めます。文字コードは UTF-8（`.m3u8`）と Shift_JIS のどちらでも構いません。

### M3U に書き出す

真ん中の欄の「…」→「M3U を書き出す…」で、いま表示しているプレイリストの曲を M3U（UTF-8）に書き出します。
ファイル名と場所は保存のダイアログで決めます。1 曲ずつ、`#EXTINF:秒数,アーティスト - 曲名` と曲の URL を並べます。

```
#EXTM3U
#PLAYLIST:マイベスト
#EXTINF:325,桑田　佳祐 - 可愛いミーナ
https://music.youtube.com/watch?v=O-XysBe_ods
```

書き出したものは曲の一覧なので、ytm-lite の「M3U を開く…」（プレイリストの URL を並べたもの）とは別物です。

### ログイン情報（cookie）の取り方

プレイリストの一覧と中身を読むのに使います。**曲の再生にはアカウントを使いません。**

#### 手動で貼り付ける（おすすめ）

1. ブラウザを、シークレット モード（InPrivate）で開く
2. https://music.youtube.com/ を開いて、ログインする（ダイアログの URL はクリックでコピーできます）
3. F12 キーを押して、開発者ツールを開く
4. 「ネットワーク」タブを開いて、F5 キーを押す
5. 一番上の行（music.youtube.com）を右クリックして、

   | ブラウザ | 選ぶもの |
   | --- | --- |
   | Chrome / Edge | 「コピー」→「cURL としてコピー（bash）」 |
   | Firefox | 「値をコピー」→「要求ヘッダー（リクエストヘッダー）をコピー」 |

6. コピーしたものを、ダイアログの欄に貼り付ける
7. ［保存］を押す
8. シークレット ウィンドウを必ず閉じる

##### なぜこの手順か

- **シークレット モードで、最後に閉じる（1・8）:** ytm-lite 専用のログインを作るためです。閉じれば、
  そのログインを使うのは ytm-lite だけになり、ふだん使っているブラウザには影響しません。
  同じログインをブラウザで使い続けると、ブラウザが cookie を入れ替えたときに ytm-lite の分が古くなって
  使えなくなったり、ブラウザ側がログオフされたりすることがあります。
- **F5 キー（4）:** 開発者ツールは、開く前の通信を記録しません。読み込み直して、通信を表に出すためです。
- **一番上の行（5）:** ページそのものの通信で、ログイン情報（cookie）がすべて載っています。

貼り付けた cookie は Windows の暗号化（DPAPI）をかけて `ytm-lite.ini` に保存します。同じ Windows ユーザーでしか戻せません。
使えなくなったら、同じ手順で取り直してください。

#### Firefox から自動で読み込む

1. ytm-lite 専用の Firefox で、music.youtube.com にログインする
2. ［Firefox から読み込む］を押す
3. 「見つからない」と出たら、［参照…］で Firefox Portable のフォルダ（`FirefoxPortable`）を選んでから、もう一度押す

以後は ytm-lite を起動するたびに Firefox から読み直します。`ytm-lite.ini` には「Firefox から読む」ことと
Firefox のプロファイルの場所だけを書き、cookie は書きません。Firefox のファイルには何も書きません。

- **専用の Firefox を使う理由:** ふだん使いの Firefox で YouTube を使い続けると、その Firefox がログオフされることがあります
  （同じログインを Firefox と ytm-lite が同時に使うため、と見ています）。Firefox Portable をもう 1 つ用意するなどしてください。
- **プロファイルの探し方:** 動いている Firefox Portable、いつものプロファイル、そのほかのプロファイルの順に見て、
  YouTube にログインしているものを使います。［参照…］ではプロファイルのフォルダも指定できます。
- ［music.youtube.com を開く］で、その Firefox で YouTube Music を開けます（ログインするため）。

Chrome / Edge は cookie を暗号化していて（Chrome 127 からの App-Bound Encryption）、外のアプリからは読めません。

## 操作

| 操作 | |
| --- | --- |
| 再生 / 一時停止 | 中央の丸いボタン、Space（一覧を選んでいるとき）、キーボードの再生キー |
| 次 / 前の曲 | ⏭ / ⏮、Ctrl+→ / Ctrl+←、キーボードの次・前キー |
| シャッフル / リピート | 真ん中の欄の 🔀 / 🔁（赤いときが有効） |
| 位置を変える | 上の横棒をクリックかドラッグ |
| 音量 | 真ん中の欄の下の横棒をクリックかドラッグ、またはマウスホイール |
| 読み直す | F5 |
| 欄の幅を変える | 欄の境目（真ん中の欄の左右の端）をドラッグ。ダブルクリックで元の幅に戻す |
| M3U を開く | 真ん中の欄の「…」→「M3U を開く…」、またはウィンドウへドラッグ＆ドロップ |
| M3U に書き出す | 真ん中の欄の「…」→「M3U を書き出す…」（いま表示しているプレイリストの曲） |

再生中の曲は Windows のメディア コントロールにも出ます。音量を変えたときに出るフライアウトや、
[muutask](https://github.com/iosxi/muutask) のようなアプリから、曲名・ジャケット画像・位置が見え、再生・一時停止・次・前・位置の変更ができます。

画面は YouTube Music に倣って 3 つの欄に分かれています。左にライブラリ、真ん中に再生中の曲のジャケット画像・曲名・シークバー・操作ボタン、右に曲の一覧（1 曲 2 段）。
曲が変わると、新しいジャケット画像が届くまでは空の枠を出します。

次へ・前へ・自動で次の曲に進んだときは、再生中の曲が一覧のなるべく真ん中に来るようにスクロールします
（一覧で曲を選んで再生したときは動かしません）。

前の曲（⏮）は、3 秒以上鳴っていればその曲の頭に戻ります。
YouTube Music で灰色になっている（再生できない）曲は飛ばします。

キーボードの再生・次・前キーは、ytm-lite が起動している間は ytm-lite が受け取ります。
ほかのアプリに渡したいときは `ytm-lite.ini` に `mediakeys=0` と書いてください。

## 設定（ytm-lite.ini）

画面から変えられないものだけ書きます。

| キー | 意味 |
| --- | --- |
| `mediakeys=0` | キーボードのメディアキーを受け取らない |
| `thumbnail=0` | ジャケット画像を取りに行かない（Windows のメディア コントロールにも、真ん中の欄にも出さない） |
| `thumbnail_size=1200` | ジャケット画像の一辺（ピクセル、60〜1200）。既定は 544 |
| `theme=1` / `theme=2` | ライト / ダークに固定する（既定は Windows に合わせる） |
| `debug=1` | 通信の記録を `ytm-lite.log` に書く |

## ログ（ytm-lite.log）

ログインまわりの出来事だけは、`debug` の設定に関係なく `ytm-lite.exe` と同じフォルダの `ytm-lite.log` に書きます。
アカウントがログオフされたとき、いつ・何が返ってきたかを後から追うためです。cookie の値は書きません。

| 行 | 意味 |
| --- | --- |
| `account browse: logged in (cookie from paste)` | ログインできている（起動してから最初の 1 回だけ書く） |
| `account browse: NOT logged in (logged_in=0, …)` | YouTube から「ログインしていない」と返った。ログオフされた |
| `account browse: HTTP 401 …` | ログイン情報が拒まれた |
| `account browse: Set-Cookie of login cookies: SID(DELETED), …` | YouTube がログインの cookie を消した・入れ替えた |
| `account …: no login cookies: …` | ログイン情報が読めない（Firefox 側がログオフされた、など） |
| `account cookies re-read from Firefox to retry` | Firefox から読み直してやり直した |

ログオフされたときは、`ytm-lite.log` を添えて知らせてもらえると原因を追えます。
1MB を超えると `ytm-lite.log.old` に回します。

## 注意

- YouTube Music の公式アプリではありません。YouTube の非公開の API を使っているので、
  YouTube 側の変更で動かなくなることがあります。
- YouTube から「要求が多すぎる」などと拒まれたときは、安全のため 30 分間、再生の要求を止めます。
- 「子ども向け」に指定された曲など、一部の曲は再生できないことがあります。
